# REBRA 포팅 메뉴얼

## 1. 프로젝트 빌드 및 배포 가이드

### 1.1 시스템 요구사항

#### 백엔드 (JVM 및 언어)
- **Java**: OpenJDK 21
- **Gradle**: 8.8.0 (Wrapper 사용)
- **Spring Boot**: 3.5.5

#### 프론트엔드 (웹 개발 환경)
- **Node.js**: 20.x 이상
- **npm**: 9.x 이상
- **Vite**: 6.3.5
- **React**: 18.3.1
- **TypeScript**: 지원

#### 웹서버 및 WAS
- **내장 웹서버**: Tomcat (Spring Boot 내장)
- **포트**:
  - 메인 서버: 8080
  - 백테스트 계산 서버: 8081

#### 개발 환경
- **IDE**: IntelliJ IDEA 또는 Eclipse
- **빌드 도구**: Gradle
- **컨테이너**: Docker & Docker Compose

#### 운영 환경
- **도메인**: **rebra.site**

## 2. 외부 서비스 연동 정보

### 2.1 카카오 OAuth 2.0 (소셜 인증)

#### 서비스 정보
- **플랫폼**: 카카오 개발자 센터
- **용도**: 사용자 소셜 로그인
- **API 문서**: https://developers.kakao.com/docs/latest/ko/kakaologin/rest-api

#### 필요 설정
```yaml
kakao:
  client-id: ${KAKAO_CLIENT_ID}
  client-secret: ${KAKAO_CLIENT_SECRET}
  redirect-url: https://rebra.site/oauth2/authorization/kakao/callback
  token-url: https://kauth.kakao.com/oauth/token
```

#### 발급 방법
1. [카카오 개발자 센터](https://developers.kakao.com/) 접속
2. 애플리케이션 등록
3. 플랫폼 설정에서 웹 플랫폼 추가
4. Redirect URI 등록: `https://rebra.site/oauth2/authorization/kakao/callback`
5. 동의항목에서 필요한 정보 설정 (닉네임, 이메일 등)

### 2.2 한국투자증권 KIS API

#### 서비스 정보
- **플랫폼**: 한국투자증권 KIS Developers
- **용도**: 실시간 주식 데이터, 계좌 정보, 주식 거래
- **라이브러리**: `com.youhogeon.finance:kis_client:0.3.10`

#### 주요 기능
- 실시간 주식 시세 조회
- 계좌 잔고 및 보유 종목 조회
- 주식 매매 주문
- 차트 데이터 조회

#### 설정 방법
1. [한국투자증권 KIS Developers](https://apiportal.koreainvestment.com/) 회원가입
2. 앱 등록 및 API Key 발급
3. 모의투자 또는 실계좌 연결 설정

### 2.3 FSS (금융감독원) Open API

#### 서비스 정보
- **플랫폼**: 공공데이터포털
- **용도**: 주식 기본 정보, 시장 지수 조회
- **API 문서**: https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15001159

#### 설정
```yaml
fss:
  api:
    base-url: "https://apis.data.go.kr/1160100/service/GetStockSecuritiesInfoService"
    market-index-base-url: "https://apis.data.go.kr/1160100/service/GetMarketIndexInfoService"
    service-key: "${FSS_API_SERVICE_KEY}"
```

#### 발급 방법
1. [공공데이터포털](https://www.data.go.kr/) 회원가입
2. "주식시세정보" API 신청
3. 승인 후 인증키 발급

### 2.4 DeepSearch API

#### 서비스 정보
- **용도**: 주식 뉴스 데이터
- **설정**: `deepsearch.api.key: ${DEEP_SEARCH_KEY}`

#### 발급 방법
1. DeepSearch 플랫폼 회원가입
2. API 키 발급 신청 후 등록

### 2.5 OpenAI GPT API

#### 서비스 정보
- **플랫폼**: OpenAI
- **용도**: AI 기반 투자 조언 및 분석
- **모델**: GPT 시리즈

#### 설정
```yaml
spring:
  ai:
    openai:
      api-key: ${OPEN_AI_API_KEY}
```

#### 발급 방법
1. [OpenAI 플랫폼](https://platform.openai.com/) 계정 생성
2. API Keys 섹션에서 새로운 시크릿 키 생성
3. 사용량에 따른 결제 정보 등록
